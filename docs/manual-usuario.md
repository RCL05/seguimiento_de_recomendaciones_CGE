# Manual de usuario de SITRA-CGE UNL

**Estado**: estructura inicial; se completará con capturas cuando la interfaz esté
funcional.  
**Versión**: 0.1.0  
**Última actualización**: 2026-10-20

## 1. Cómo entender el sistema

Una recomendación sigue este recorrido:

```text
Pendiente
  -> En Planificación
  -> En Ejecución
  -> En Revisión Interna
  -> Cumplida
```

Si la UAI encuentra problemas, pasa a `Rechazada/Corrección`. Si vence sin
evidencia aprobada, pasa a `En Mora`.

## 2. Qué puede hacer cada persona

| Persona | Puede hacer |
|---|---|
| DTI | Administrar cuentas, roles y dependencias |
| UAI | Registrar informes, asignar recomendaciones, revisar y dictaminar |
| Ejecutor | Crear plan y cargar evidencias de su dependencia |
| Rectorado | Consultar indicadores y unidades en mora |
| Auditor CGE | Consultar historial y verificar integridad autorizada |

## 3. Flujo del ejecutor

1. Iniciar sesión.
2. Abrir una recomendación asignada.
3. Crear el plan de acción.
4. Registrar hitos y fechas.
5. Cargar un PDF.
6. Revisar el resultado de la UAI.
7. Corregir observaciones si la evidencia fue rechazada.

## 4. Flujo de la UAI

1. Registrar el informe CGE.
2. Crear la recomendación y asignar unidad y plazo.
3. Consultar evidencias en revisión.
4. Aprobar o rechazar con observaciones.
5. Consultar la bitácora.
6. Exportar la matriz institucional.

## 5. Ayuda rápida

- **No puedo ver una recomendación**: verifica que pertenezca a tu dependencia.
- **No puedo cargar un archivo**: confirma que sea un PDF válido y no exceda el
  tamaño permitido.
- **La recomendación no se marca cumplida**: la UAI debe revisarla y aprobar una
  evidencia.
- **No llegó una alerta**: la configuración y el estado de envío deben revisarse
  con DTI.
