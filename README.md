# : Seguimiento de Recomendaciones CGE - UNL :


Sistema para la gestión, seguimiento y trazabilidad de recomendaciones emitidas por la Contraloría General del Estado (CGE) para la Universidad Nacional de Loja (UNL).

## Estado del proyecto

La planificación funcional, técnica y de tareas se encuentra en
[`specs/001-seguimiento-recomendaciones/`](specs/001-seguimiento-recomendaciones/).
La implementación inicial del dominio está en [`backend/`](backend/).

La documentación del proyecto está organizada en [`docs/`](docs/):

- [Hoja de ruta](docs/hoja-de-ruta.md): qué se construye y en qué orden.
- [Equipo y responsabilidades](docs/equipo-y-responsabilidades.md): distribución
  para cuatro integrantes.
- [Trazabilidad](docs/trazabilidad.md): relación entre necesidad, requisito,
  tarea, código, prueba y manual.
- [Manual técnico](docs/manual-tecnico.md).
- [Manual de usuario](docs/manual-usuario.md).
- [Flujo Spec Kit](docs/flujo-speckit.md): secuencia de trabajo y hooks opcionales.

## 🛠️ Requisitos Previos

Antes de comenzar, asegúrate de tener instalado el siguiente software en tu equipo:

* [Git](https://git-scm.com/) (Controlador de versiones)
* [GitKraken](https://www.gitkraken.com/) (Cliente gráfico para Git)
* [Visual Studio Code](https://code.visualstudio.com/) (Editor de código/texto)
